# Medureon ERP

This repository contains the Medureon Pharmacy ERP backend and API documentation.

## Backend API Documentation

The full API reference for the server is available in [server/README.md](server/README.md).

## Quick start

```bash
cd server
npm install
npm run dev
```

The API server runs on:

```text
http://localhost:5000/api/v1
```

## Main modules

- Authentication
- Suppliers
- Categories
- Products and batches
- Inventory transactions and stock-in
- Customers, sales, invoices, and lendings
- Analytics, reports, notifications, and settings
- Employees and attendance
- Uploads and exports
